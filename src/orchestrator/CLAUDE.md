# src/orchestrator

Modules called by `agents/manager-daemon.ts` facade in response to bus events.

| file | use |
|---|---|
| `tick-loop.ts` | 30s reconciliation. Health check, stale recovery, queue process, delegation/escalation cleanup, checkpoint persist, log retention. Hourly `autoDeleteOldTasks` sweep deletes `settled` tasks past a configured age (`settled_at`, fallback `updated_at`), with separate day-windows for one-off vs recurring-run tasks (`app_settings.task_retention_days` / `recurring_task_retention_days`, 0 = off); deletes via `TaskScheduler.deleteTask` for the full cascade. 5-min `rotateOversizedLogFile` caps the daemon's stdout/stderr `skipper.log` (snapshot → `.old` + in-place truncate; `SKIPPER_LOG_MAX_BYTES`, default 25 MB) — only when fd 1 is that file, so dev runs are untouched |
| `task-runner.ts` | Queue: pull next startable task (`getNextStartableTask`) under the concurrency cap (slot = active task with live agents or paused). First start spawns the entrypoint with prompt + phase context; a wake appends the pending INPUT_FEED block (from the input pipeline's `consumePendingFeed`) to the full resume/cold prompt. Teamless conversational tasks feed via the pipeline (`TaskWakeFeeder.feedTask`) |
| `phase-manager.ts` | `[PHASE_COMPLETE]` + `[PHASE_REGRESSION]` handling. Regression respawn + dedup guards |
| `delegation-manager.ts` | Delegation signals. Spawn child instance/batch. Track groups. Resume parent on complete. Timeout 60min. **Delegated children may delegate onward** — `delegate`/`delegate_batch`/`delegate_resume` are gated only by `!isSolo` (`mcp/tools.ts`), not by `isDelegated`, so nesting is allowed. No numeric depth / per-parent / batch-size cap is enforced (`getDelegationDepth()` exists but is currently uncalled). Nesting is bounded structurally instead: no self-delegation; a non-entrypoint cannot delegate to the entrypoint; **cycle guard** `isAncestorTemplateInActiveChain` blocks delegating to a template already an ancestor in the active pending/running chain; **one active delegation group per parent** at a time; target must be in the same team (or the task's assigned-agent set); parent must support stdin or resume. Optional per-delegation working directory (`delegate`'s `working_directory` → `delegations.working_directory`): sets the child's `WORKING DIRECTORY:` prompt line **and** its spawn cwd — the only case where a child does not start in the orchestrator's cwd. `validateWorkingDirectory()` (exported here) requires an absolute path that exists; a retry/resume replays the stored value. **Resume drains the pending input feed:** `routeResultToParent` (parent resume on delegation complete) enriches the result payload with unseen notes AND, via the injected `TaskWakeFeeder` (`setWakeFeeder`, the same `RealtimeSessionManager`), any operator input that arrived while the delegation was open (`consumePendingFeed`) — committed (`fed_to_skipper=1`) only on a delivery path that actually reaches the parent (running-parent `sendInput`, or successful async resume); a failed/orphaned resume leaves the feed unfed so the next run redelivers it. Without this, mid-delegation input stayed "queued for agent" until a whole new run started, and the resuming parent could conclude on stale context |
| `recovery-manager.ts` | Startup cleanup, stale-task recovery (WORKFLOW mode only; conversational tasks rest idle and re-feed on input; skips tasks marked idle-at-rest by a clean root exit — the `idle_since:` daemon_state key — which belong to idle-poke-manager, so a deliberate stop is nudged/escalated instead of crash-recovered), checkpoint R/W, orchestration state persist, one-shot recovery safeguard (exhaustion now `failRun` + step IDLE, task stays active; new input resumes) |
| `health-monitor.ts` | Liveness, orphan detect, stuck diag (30min, 3 nudges), clustered-exit escalate |
| `artifact-manager.ts` | Versioned immutable artifacts. CRUD called from MCP tools (`create_artifact`/`get_artifact`/`list_artifacts`). Bodies carry a `format` (`html`\|`markdown`); `createArtifact` resolves it (explicit, else `looksLikeHtml` inference) and, when it resolves to `html`, runs `html-validator.ts` inline — a failed validation throws `ArtifactHtmlValidationError` (line/col/tag) and nothing is persisted. Per-version publish state (`publishArtifact`/`unpublishArtifact`/`getPublishedArtifact`) for public links via connect. **File artifacts** (operator uploads, `kind='upload'`, `storage='file'`): `createFileArtifact` validates (25 MB cap `MAX_FILE_ARTIFACT_BYTES`; a declared `image/*` must sniff as PNG/JPEG/WebP/GIF via `image-meta.ts`, whose mime + dimensions then win; other mimes are taken as declared, fallback `application/octet-stream`), computes sha256, writes the bytes ONCE to `<data dir>/artifacts/<taskId>/<id>.<ext>` (`artifact-files.ts`; constructor option `artifactsRoot` overrides for tests), inserts the row with `body` = caption (empty string when none), emits `artifact:created`. `getArtifactFilePath` / `readArtifactBytes` (null for inline). `artifactToJson` is the HTTP projection (file rows: no body, `description` + `file_url`). Chunked upload sessions for connect: `beginUpload` (size/mime/sha256 checks) → `appendChunk` (sequential index, declared-size guard) → `commitUpload` (size + sha256 verify, then `createFileArtifact`) / `abortUpload`; in-memory, 2 min idle expiry (`UPLOAD_SESSION_TTL_MS`) |
| `artifact-files.ts` | On-disk layout helpers for file artifacts: `getArtifactsRoot()` (`<data dir>/artifacts`), `taskArtifactDir`, `removeTaskArtifactFiles(taskId)` (called by `TaskScheduler.deleteTask`), `sanitizeArtifactFileName` (the versioning key is the sanitised original filename, so a re-upload of the same name becomes the next version), `fileExtensionFor`, `mimeFromExtension` (small extension→mime map for the `create_file_artifact` tool: images, pdf, txt, md, csv, json, zip, mp4, mov, wav, mp3, log, html; null otherwise), `formatBytes` |
| `image-meta.ts` | `detectImage(bytes)`: dependency-free magic-byte sniff + header dimension parse for PNG/JPEG/WebP/GIF. `image-fixtures.ts` builds minimal header-only fixtures for tests |
| `html-validator.ts` | `validateArtifactHtml(body)` — dependency-free tag-stack parser that rejects malformed artifact HTML (mismatched/unclosed tags, disallowed `script`/`style`/`iframe`/document-wrapper tags) with the line/column where the node tree broke. Bun's `HTMLRewriter` is too lenient to catch these. Called by `artifact-manager.ts` at create time |
| `realtime-session.ts` | Universal input pipeline (every task): recording lock + cadence audio ingest, transcribe, summarize, timeline entries. Text ingest is sessionless (any active task). Feeds route through `TaskScheduler.requestWake` → queue → task-runner (cap-respecting); implements task-runner's `TaskWakeFeeder`. `prepareTaskForInput(taskId)` is the shared admission step for any input (settled → `reviveTask`, open review gate → cleared; returns `draft`/`active`), used by `ManagerDaemon.inputTask` and by `ingestArtifactUpload(taskId, artifact, {caption?, source})`, which inserts an `image`/`file` `realtime_timeline` row (`content` = caption else filename, `artifact_id`, priority high, unfed), emits `realtime:timeline_updated` + `realtime:window_ready`, then applies the same wake semantics as text (draft = stored, consumed by the first run's `consumePendingFeed`; active → `requestWake`, busy roots accumulate). Both feed formatters (`consumePendingFeed` and `feedSkipper`) go through `formatFeedLine`: upload entries render as `[HH:MM:SS IMAGE PRIORITY:HIGH] Operator attached an image artifact "name" (v2, 2048x1536): <abs path> - caption: "...". View it with your file/image reading tool before you continue.` (files: `(v1, application/pdf, 1.2 MB)` + `Read it with your file-reading tool...`); the bytes never travel through the prompt. `ingestAgentArtifact(taskId, artifact, {agentId})` is the agent-output counterpart (the `create_file_artifact` MCP tool): inserts the `image`/`file` row with `fed_to_skipper = 1`, priority `normal`, emits only `realtime:timeline_updated`; no status change, no wake, no `realtime:window_ready`, and the feed queries skip it |
| `idle-poke-manager.ts` | Nudge stuck agents that go silent (workflow-mode tasks only; settled runs at step IDLE rest) |
| `state.ts` | `TaskOrchStep` state machine. Transition validate + log |
| `phase-config.ts` | `resolvePhaseConfig()` — merge team base phase + per-task `task_config.phase_overrides` (prompt + review gate) |
| `types.ts` | `OrchestrationState`, `TaskCheckpoint`, regression metadata |

## Phase advancement

Non-streaming agents advance on exit code 0 via `handleSuccessfulExit`. Active delegation blocks completion — check `getActiveDelegationForParent` first.
